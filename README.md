# ♻️ Erecycle - E-Waste Locator and Management Platform

<img width="1899" height="984" alt="Screenshot 2025-08-31 000042" src="https://github.com/user-attachments/assets/1eb4c0d9-ca7a-4a5c-9e94-b538d21821c7" />

Erecycle is a **web platform for E-Waste Management** that helps people and businesses **locate reliable e-waste recycling centers** near them.  
It solves the problem of improper e-waste disposal by offering a **dynamic, user-friendly, and scalable MERN application built with TypeScript**.  

🌍 Live Demo: [Erecycle](https://erecycle.vercel.app)

---

## ✨ Features
- 📍 **E-Waste Facility Locator**
  - Find nearby e-waste centers using location-based services
  - Interactive maps with center details
- 🛠 **Recycling Services**
  - Smartphone recycle
  - Laptop recycle
  - Other electronics management
- 🔐 **Authentication**
  - Secure login/register (JWT/OAuth)
  - User profiles & booking history
- 🗑 **E-Waste Collection Requests**
  - Users can schedule pickup/drop-off requests
  - Admin manages collection centers
- 📊 **Admin Dashboard**
  - Add/update recycling centers
  - Manage users and requests
- 📱 **Responsive UI**
  - Fully optimized for desktop and mobile

## 🛠 Tech Stack

**Frontend**
- React + TypeScript
- TailwindCSS
- React Router

**Backend**
- Node.js + Express + TypeScript
- MongoDB + Mongoose
- JWT Authentication

**APIs & Tools**
- Google Maps API / Leaflet.js for location
- Geolocation API
- Nodemailer (optional for notifications)

**Deployment**
- Frontend → Vercel
- Backend → Render / AWS
- Database → MongoDB Atlas
